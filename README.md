# ThunderCam

Вычислительная камера для бюджетных телефонов. Форк [GrapheneOS Camera](https://github.com/GrapheneOS/Camera) (MIT) + собственный конвейер обработки.

База даёт стабильный захват без багов, наше — картинку уровня стока и выше.

## Что внутри

- **P0-обработка** — тон, контраст, насыщенность, баланс белого + шумодав. Готовые стили (стандарт/еда/портрет/ночь/документ/пейзаж), калибровка под свой сенсор за 2 тапа
- **HDR** — серия 2–3 кадров с равнением и мержем (~2–4 с), нативный exposure fusion с анти-гостингом; третий кадр снимается только если тени реально провалены
- **Ночь** — серия до 5 кадров с декодом «на лету» и стеком √N, перенос деталей с полного разрешения опорного кадра
- **Зум-адаптив** — цифра поверх оптики HAL (минимум ×2, зверь — до 100× тотал) + ИИ-апскейл: вшитые, скачиваемый x4plus или своя ссылка, бленд сеть/реал регулируется
- **Трекинг фокуса** — долгий тап ведёт объект (фото и видео), 15fps, coast при рывках
- **Галерея «Улучшить»** — отдельный экран: шумодав + ИИ-свет Zero-DCE, сравнение удержанием, копия или перезапись
- **Понятный интерфейс** — простой вид по умолчанию (стиль, шумодав, ночь, HDR, авто-сюжет, профили Быстрый/Сбалансированный/Максимум) и «Показать все настройки» для экспертов
- **Русский язык**, подписи к иконкам, онбординг первого запуска

## Сборка

Нужны Android SDK 37, NDK 25.1.8937393 и JDK 21.

```bash
./gradlew :app:assembleDebug        # debug APK
./gradlew :app:testDebugUnitTest    # юнит-тесты
```

Релиз подписывается через `keystore.properties` в корне (в git не попадает, см. `.gitignore`).
CI (GitHub Actions) собирает debug APK и гоняет тесты на каждый пуш.

## Стек

Kotlin, CameraX 1.6 (SessionConfig), TFLite (GPU-делегат → CPU), OpenCV, JNI (NEON), ML Kit. Только arm64.

## Статус

В активной разработке, тестируется на Tecno LH7n. Релиза пока нет.
