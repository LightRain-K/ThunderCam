# ThunderCam

Вычислительная камера для бюджетных телефонов. Форк [GrapheneOS Camera](https://github.com/GrapheneOS/Camera) (MIT) + собственный конвейер обработки.

База даёт стабильный захват без багов, наше — картинку уровня стока и выше.

## Что внутри

- **P0-обработка** — тон, контраст, насыщенность, баланс белого + шумодав. 6 слайдеров рецепта, мастер калибровки под свой сенсор за 2 тапа
- **HDR** — серия 0/−/+ с равнением и мержем (~12с), нативный exposure fusion с анти-гостингом, честный фолбэк в одиночный при тряске
- **Зум-адаптив** — цифра поверх оптики HAL (минимум ×2, зверь — до 100× тотал) + ИИ-апскейл: вшитые, скачиваемый x4plus или своя ссылка, бленд сеть/реал регулируется
- **Трекинг фокуса** — долгий тап ведёт объект (фото и видео), 15fps, coast при рывках
- **Галерея «Улучшить»** — отдельный экран: шумодав + ИИ-свет Zero-DCE, сравнение удержанием, копия или перезапись
- **Русский язык**, кнопка всех настроек с главного экрана, тумблеры на каждую функцию

## Стек

Kotlin, CameraX 1.6 (SessionConfig), TFLite (GPU-делегат → CPU), OpenCV, JNI (NEON), ML Kit. Только arm64.

## Статус

В активной разработке, тестируется на Tecno LH7n. Релиза пока нет.
